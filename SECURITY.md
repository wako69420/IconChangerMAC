# Security

Icon Changer is a solo passion project. While I try my best to ensure the code is safe and relies on native macOS APIs, there are no actively supported enterprise versions.

## Reporting a Vulnerability

**Please do NOT open a public GitHub issue for security vulnerabilities.**

If you happen to discover a security flaw or vulnerability in the code, please report it privately to me. You can reach out directly via my GitHub profile email or use GitHub's private vulnerability reporting feature.

Publicly disclosing a vulnerability before it can be addressed puts anyone using the app at risk. Please just be responsible, don't exploit anything maliciously, and let me know privately!
