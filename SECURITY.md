# Security

Since Icon Changer was just a solo passion project (and is now completely archived), there are no actively supported versions. 

If you happen to find a crazy security flaw or vulnerability in the code, feel free to open an issue and tag it as `security` just so others are aware of it. Since I'm not actively updating the app anymore, I probably won't patch it, but documenting it for anyone else using the code is super helpful.

Please just be responsible and don't exploit anything maliciously!
