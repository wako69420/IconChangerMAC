# Security Policy

## Supported Versions

Since this project is **archived**, there are no actively supported versions. 

| Version | Supported          |
| ------- | ------------------ |
| 1.3.x   | :x: (Archived)     |
| < 1.3.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please note that this is an archived learning project. 

However, if you find a critical flaw that you believe should be addressed for historical purposes or for anyone using the code, please open an issue in the repository with the label `security`.

Do not exploit the vulnerability. Provide detailed steps on how to reproduce it so that we can evaluate the impact.
