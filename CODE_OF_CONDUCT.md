# Code of Conduct

As this is a solo passion project, the rules are pretty simple:

- **Be respectful:** Treat everyone with respect. Harassment, abusive language, or personal attacks will not be tolerated.
- **Be constructive:** If you are opening an issue or PR, please provide constructive feedback and clear explanations.
- **Have fun:** We are all here to learn and build cool things for macOS!

Any behavior that violates these simple guidelines may result in being blocked from participating in the repository.
